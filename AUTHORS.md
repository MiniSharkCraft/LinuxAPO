# Authors and Contributors

LinuxAPO (SkyAPO) is maintained in the [MiniSharkCraft/LinuxAPO](https://github.com/MiniSharkCraft/LinuxAPO) repository.

## Project maintainers

- [MiniSharkCraft](https://github.com/MiniSharkCraft), repository owner and project maintainer.

## Contributors

See the [GitHub contributors page](https://github.com/MiniSharkCraft/LinuxAPO/graphs/contributors) and the project's Git history for contributions and attribution.

LinuxAPO integrates upstream Equalizer APO code and other third-party components. Their respective authorship, license notices, and attribution must remain intact. Consult [COPYING](COPYING), the submodules, and relevant upstream license files.

To request an attribution correction, open an issue with the relevant commit or source reference.
