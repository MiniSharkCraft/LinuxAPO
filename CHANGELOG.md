# Changelog

## 0.9.0 — daily-use preview (2026-10-01)

- Set the supported release scope to the locally verified PipeWire/DSP/virtual-mic path, transactional config lifecycle, bounded supported plugin/PDC behavior, and Arch staged-install workflow. This is a preview, not 1.0.0 or production-final.
- Defer real hardware unplug/replug, clean-root/ALPM-hook and hosted-CI evidence, legal/distribution resolution, complete Windows EAPO parity, arbitrary third-party plugin guarantees/isolation, and total end-to-end latency to the explicit 1.0.0 backlog in `ROADMAP.md`.
- Add a 10,000-sample ceiling for plugin-reported realtime latency and compensation rings; reject oversized initial values and silence an instance that reports an oversized dynamic value, then rebuild its compensation schedule off-thread. Other unexpected PDC refresh failures remain fail-closed rather than resuming with a potentially stale channel alignment.
- Verify the full local PipeWire-enabled regression (58/58, including recovery and supported plugin-latency/PDC E2E), ASan/UBSan with LeakSanitizer enabled (35/35), and an Arch package rebuilt from source commit `378a49d` (CTest 34/34, staged payload smoke, offscreen UI, and installed offline WAV `-6 dB` check). A full pacman install/remove transaction and clean-root/ALPM hook validation remain deferred to 1.0.0.
- Bound aggregate plugin-latency compensation ring storage to 16 MiB and reject candidate graphs that exceed the budget before allocating ring buffers; a many-branch Copy/PDC fixture verifies rejection. Re-ran the full CTest suite (58/58) and strict ASan/UBSan/LeakSanitizer suite (35/35); both pass. Arch `skyapo-0.9.0-3` from commit `955c0d4` passed package CTest 34/34, staged install/UI/renderer smoke and the extracted package's actual offline `-6 dB` WAV check. Documentation-only pkgrel `-4` and `-5` repackages kept the tested binary payload unchanged; both passed staged smoke, and both extracted renderers passed the actual offline `-6 dB` WAV check. Pkgrel 5 uses documentation from commit `e0b4121`. `namcap` completed with the missing-source-URL and dependency warnings recorded in `ROADMAP.md`.
- Built Debian amd64 and RPM x86_64 packages with CPack and inspected their metadata/dependencies and payload/license paths. Extracted DEB, RPM and generic x86_64 tar payloads pass CLI version/help, daemon/service/license presence and actual offline `Preamp: -6 dB` WAV sample checks. Nix `flake check` builds the pinned package and passes its scoped 32/32 tests and CLI/package smoke (UI and hardware-dependent E2E are intentionally disabled). These checks are not full distro install transactions.
- Release identity remains intentionally unresolved: the pre-existing `v0.9.0` tag points to historical commit `0705764`, while the current source is newer. The existing tag was not moved or overwritten.
- Generated `release-artifacts/SHA256SUMS` for the Arch, Debian, RPM and generic tarball artifacts; `sha256sum --check` passed for all four. The existing `v0.9.0` tag was not moved and still points to the older release commit documented in `ROADMAP.md`.
