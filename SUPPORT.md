# LinuxAPO Support

LinuxAPO (SkyAPO) is a beta Linux audio DSP project. Some hardware combinations, legacy Equalizer APO directives, and third-party plugins remain unverified.

## Where to ask

- **Usage questions and setup help:** [GitHub Discussions](https://github.com/MiniSharkCraft/LinuxAPO/discussions)
- **Reproducible bugs:** [GitHub Issues](https://github.com/MiniSharkCraft/LinuxAPO/issues)
- **Feature proposals:** Discussions first; open an issue when the proposal is actionable.
- **Sensitive security reports:** Follow [SECURITY.md](SECURITY.md).

## Before posting

Read [README.md](README.md) and the relevant documentation in [docs/](docs/), especially configuration and plugin limitations.

For a bug report, provide the Linux distribution, PipeWire version, LinuxAPO version or commit, relevant device/plugin information, exact steps to reproduce, expected and actual results, and redacted diagnostic output. Mention whether the problem occurs in the offline renderer, realtime daemon, or Qt editor.

Never publish passwords, tokens, private audio recordings, or identifying logs.

## Expectations

Support is community- and maintainer-driven. Responses, compatibility fixes, and release dates are not guaranteed.
