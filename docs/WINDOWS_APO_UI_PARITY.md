# Equalizer APO 1.4.2 Windows UI parity audit

This audit compares the supplied screenshots with the Linux editor source and
tests in this worktree. It is a source/UI audit, not a claim of complete EAPO
feature parity. All 16 files in `example-windows/` were enumerated and viewed
together in a contact sheet; the main editor, Add Filter category/menu views,
analysis panel, Device Selector, and test-success/failure dialogs were also
inspected at full resolution. Screenshot filenames are descriptive and match
their contents. No screenshot was changed.

Statuses describe the screenshot's function, not pixel similarity:

- **IMPLEMENTED AND VERIFIED** — corresponding Linux behavior has an
  automated test or direct runtime evidence.
- **IMPLEMENTED BUT INCOMPLETE** — related Linux behavior exists, but a
  meaningful portion of the reference workflow is absent.
- **UI ONLY** — controls are present without corresponding verified behavior.
- **NOT IMPLEMENTED** — no corresponding Linux workflow was found.
- **BLOCKED** — implementation depends on missing permission, hardware, or
  external compatibility infrastructure.
- **NOT APPLICABLE ON LINUX** — the Windows mechanism has no literal Linux
  equivalent; this does not imply that its user-facing goal is unnecessary.

## Review notes and scope boundaries

- The current source reports project version `0.9.0`; this audit does not
  change version, tags, releases or published history.
- The pinned EAPO submodule is the existing project pin; this work does not
  update it.
- PipeWire playback and capture are separate graphs. Private-graph success and
  one physical sink measurement are not proof across desktop policies,
  devices, or arbitrary applications.
- Windows pre/post-mix, APO registration, service restart, registry, and DLL
  layout are Windows-specific. LinuxAPO should provide meaningful PipeWire
  status and controls, not counterfeit those labels.
- Polkit is not automatically warranted for per-user PipeWire graph changes.
  Any privileged operation needs a separately scoped security review.
- The UI artwork in the current uncommitted tree has an unresolved
  redistribution-rights warning in `docs/UI_LICENSE_AUDIT.md`; it is not part
  of this parity change.
